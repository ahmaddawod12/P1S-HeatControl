# Firmware 1.0.1

After a power cut or restart, the controller restores the last saved heating
enable state. The heater relay starts off and can energize at the saved target
once startup checks pass and the sensor reports three consecutive valid
readings. If heating was disabled, it stays off.

Monitor P1S starts off after a reboot. Firmware updates disable heating before
installation, so the controller starts with heating disabled after an OTA
update.

Use **Update firmware** in the dashboard on a controller running the signed
public v1.0.0 baseline. The signed application targets classic ESP32-WROOM-32
boards with 4 MB flash and active-high relays. Saved Wi-Fi and printer
connection settings, target, and calibration are preserved.
