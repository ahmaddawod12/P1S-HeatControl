# Firmware 1.0.1

This release packages the current P1S-HeatControl firmware for classic
ESP32-WROOM-32 controllers with 4 MB flash and active-high relays.

- Monitor P1S keeps chamber heating coordinated with printer state: pauses,
  stale or lost printer reports, completed jobs, and the no-print timeout
  inhibit or stop monitored heating as appropriate.
- Temperature acquisition runs once per second. Four consecutive failed reads
  retain the existing heater output; the fifth latches a sensor fault. A stalled
  acquisition faults after two seconds, and over-temperature bypasses the retry
  allowance.
- Fault shutdown from an enabled session runs the circulation fan for ten
  seconds. Recovery requires three valid temperature readings.
- Runtime, Wi-Fi, and update coordination fixes improve maintenance isolation,
  printer connection recovery, and dashboard status handling.
- GitHub Actions builds, checks, signs, and publishes releases from committed
  source when the firmware version changes.

Use **Update firmware** in the local dashboard after the initial signed USB OTA
setup. Stop Monitor P1S before updating. Heating remains disabled after reboot;
normal updates preserve saved Wi-Fi and printer configuration, target, and
calibration.

The two assets are the signed generic application and `firmware.json`, which
records its size and SHA-256 digest. They contain no compiled Wi-Fi credentials.
The hardware profile remains active-high: heater GPIO16 and fan GPIO17 are OFF
at LOW and start OFF.

Physical heater/fan commissioning and on-board validation of this release remain
pending. The USB upload attempted on November 14 stopped during serial backup
and RAM-loader communication, before any firmware flash write.
