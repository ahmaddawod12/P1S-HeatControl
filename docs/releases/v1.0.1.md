# Firmware 1.0.1 OTA test

Temporary release for testing the signed update from firmware 1.0.0 on the
ESP32 pilot controller. It uses the same firmware features as 1.0.0 with an
incremented version for the test.

With heating and Monitor P1S off, choose **Check and install update** under
**Firmware** in the owner's dashboard. Wait for version 1.0.1 and **Installed**.
