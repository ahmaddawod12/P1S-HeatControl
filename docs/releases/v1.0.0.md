# Firmware 1.0.0

The first Firebase dashboard release supports multiple paired controllers.
Each controller appears in the dashboard of the account that paired it.

- The dashboard shows temperature, printer state, available RAM, and firmware status.
- Monitor P1S listens for print-state changes from the printer.
- Each board generates and stores its own password for the Wi-Fi setup hotspot.
- Owners can check for and install signed firmware from the dashboard while the controller is idle.

The release targets classic ESP32-WROOM-32 controllers with 4 MB flash and one
active-high GPIO16 relay. Use USB to install this baseline if the installed
firmware reports version 1.0.0 or higher. A controller that already uses the
same partition layout can retain saved settings during the USB installation.
See the [USB setup and OTA guide](https://github.com/ahmaddawod12/P1S-HeatControl/blob/v1.0.0/docs/ota-release-guide.md).

The GitHub assets contain the signed application and its manifest. On a blank
board, follow the USB setup guide to install the bootloader and partition table.
