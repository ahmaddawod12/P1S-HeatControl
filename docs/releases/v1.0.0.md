# Firmware 1.0.0

First release from the public P1S-HeatControl source repository. Firmware updates
now use this repository's releases.

- Active-high relays: OFF = LOW, ON = HIGH. Heater GPIO16 and fan GPIO17 start
  OFF, with heating disabled after every boot.
- Temperature calibration offset from -10 to +10 °C, applied immediately and
  saved for future boots.
- HTTP request deadlines cover blocking reads; rejected bodies close promptly.
- Fault acknowledgement waits for the controller's decision. Diagnostics retain
  the initial safe state and subsequent state/fault transitions.
- Optional local P1S monitoring; automatic preheat/Resume remains disabled by
  default pending printer qualification.

Controllers running the previous development releases (including 1.0.5) need a
one-time signed USB installation of this baseline. They use the former update
repository and reject older versions. Follow the
[USB setup guide](https://github.com/ahmaddawod12/P1S-HeatControl/blob/v1.0.0/docs/ota-release-guide.md)
with relay loads disconnected before commissioning this polarity.

The assets are the signed generic application and `firmware.json`. Public
firmware contains no compiled Wi-Fi credentials; normal updates preserve saved
credentials, target and calibration. Hardware flashing and physical relay
commissioning have not been performed for this release.
