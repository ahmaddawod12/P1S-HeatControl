# Firmware 1.1.0 verification

Published directly on November 14, 2026, at the owner's request, without CI:
[Firmware 1.1.0](https://github.com/ahmaddawod12/P1S-HeatControl/releases/tag/v1.1.0).
The earlier v1.0.1 workflow was cancelled before publication. No workflow ran
for the v1.1.0 source commit.

- Source tag: `v1.1.0`, commit `defe96a5535fb06f823b09357b63ad295abf6d1e`.
- Local firmware-source checks passed: 124 host tests, 48 dashboard tests,
  31 Python tool tests, and all 10 publisher safeguard cases.
- The final v1.1.0 generic firmware rebuilt with ESP-IDF 6.1 and passed the
  compiled printer stack check. The local publisher rebuilt the clean committed
  source again and verified that the signed package matched its application.
- The existing signing key was retained. Package checks verified the signature,
  embedded public key, version, hardware/layout identity, generic build purpose,
  and absence of compiled Wi-Fi credentials.
- GitHub identifies v1.1.0 as its latest stable release. Its two assets are
  `p1s-heat-controller-esp32-4mb.bin` and `firmware.json`.
- Both assets downloaded anonymously and matched the local package byte for
  byte. Signature and manifest checks passed on the downloaded copies. The
  anonymous latest-release API also returned v1.1.0.

Signed application: 1,245,172 bytes, SHA-256:

```text
38d7230a6937b4b06b6911696c442f53c5c4e876ec327e31c648ce8c7e8992c2
```

Physical commissioning and on-board validation remain pending. The USB attempt
on this date stopped before any firmware flash write because serial backup and
RAM-loader communication were unreliable. Publishing this release did not flash
the connected board.
